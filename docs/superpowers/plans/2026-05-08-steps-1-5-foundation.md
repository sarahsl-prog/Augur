# Augur Steps 1–5 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land a locally-runnable Augur foundation: ADK-wrapped triage agent that classifies real CICIDS alerts via Vertex Gemini, with every invocation auto-traced into Phoenix Cloud, validated by a 25-alert smoke run.

**Architecture:** Single Python package (`src/augur/`) running as a FastAPI app on uvicorn. One ADK `Agent` instance (the triage agent, single hardcoded prompt — router + per-tactic prompts arrive at step 6). OpenInference's `GoogleADKInstrumentor` auto-instruments LLM and tool spans into Phoenix Cloud free tier. Pydantic v2 schemas enforce boundaries. CICIDS preprocessing produces JSONL alerts paired with held-out ground truth. No Cloud Run deploy in this slice (that's step 11) — the Dockerfile is ready and tested but not pushed.

**Tech Stack:** Python 3.12, uv (package mgr), FastAPI + uvicorn, Google ADK (`google-adk`), Vertex AI Gemini, OpenInference (`openinference-instrumentation-google-adk` + `arize-phoenix-otel`), Phoenix Cloud, pydantic v2, pytest, ruff (lint/format).

**Source spec:** `docs/superpowers/specs/2026-05-08-augur-v1-design.md` — read it before starting; it owns the data model and acceptance criteria this plan implements.

```python
"""Phoenix Cloud + OpenInference tracing setup for Augur.

Call ``init_tracing()`` exactly once at process startup, before any ADK
agent runs. Auto-instrumentation captures every LLM call and tool span;
no manual span management is required for the triage agent.

Disabled when AUGUR_TRACING_DISABLED=1 (set by tests/conftest.py for
unit tests). The Task 6 smoke test runs in a subprocess that doesn't
inherit the disable flag.
"""

import logging
import os

logger = logging.getLogger(__name__)

_initialized = False


def init_tracing(project_name: str = "augur") -> None:
    """Register Phoenix Cloud + auto-instrument ADK. Idempotent."""
    global _initialized
    if _initialized:
        return
    if os.environ.get("AUGUR_TRACING_DISABLED") == "1":
        logger.info("Tracing disabled via AUGUR_TRACING_DISABLED — skipping init")
        _initialized = True
        return

    api_key = os.environ.get("PHOENIX_API_KEY")
    if not api_key:
        raise RuntimeError(
            "PHOENIX_API_KEY env var is required for tracing. "
            "Set it from your Phoenix Cloud account, or set "
            "AUGUR_TRACING_DISABLED=1 to skip tracing entirely."
        )

    # Imports are inside the function so the module can be imported in
    # disabled-tracing contexts without pulling in the OTel stack.
    from openinference.instrumentation.google_adk import GoogleADKInstrumentor
    from phoenix.otel import register

    tracer_provider = register(
        project_name=project_name,
        endpoint="https://app.phoenix.arize.com/v1/traces",
        headers={"api_key": api_key},
        auto_instrument=True,
    )
    GoogleADKInstrumentor().instrument(tracer_provider=tracer_provider)
    _initialized = True
    logger.info("Phoenix tracing initialized (project=%s)", project_name)
```

from google.adk.runners import InMemoryRunner
from google.genai import types

from augur.agents.stub import build_stub_agent

async def main():

        user_id="smoke",

```python
"""Pydantic schemas for Augur alert, ground truth, and triage output.

Schemas enforce hackathon-track invariants at runtime: invalid
dispositions, tactics, severities, or confidence values raise
ValidationError before they can corrupt downstream state.

Aligned with augur-mitre-taxonomy skill — the structured output schema
field set must match exactly.
"""

from datetime import datetime
from typing import Literal

from pydantic import BaseModel, ConfigDict, Field

from augur.data.enums import Disposition, Tactic

# Tactic in ground truth may be "Not Applicable" when disposition is
# False Positive (no real attack present). All other strings are rejected.
TacticOrNotApplicable = Tactic | Literal["Not Applicable"]


class RawSignals(BaseModel):
    model_config = ConfigDict(extra="allow")  # CICIDS has many derived features
    src_ip: str
    dst_ip: str
    dst_port: int
    protocol: Literal["TCP", "UDP", "ICMP"]
    flow_duration_ms: int
    packet_count: int
    byte_count: int
    flags: list[str] = Field(default_factory=list)


class AlertContext(BaseModel):
    host_role: Literal["workstation", "domain_controller", "server", "unknown"]
    user_account: str | None = None
    is_business_hours: bool


class Alert(BaseModel):
    """Input to the triage agent. NEVER includes ground truth."""

    alert_id: str
    timestamp: datetime
    source: Literal["cicids2017", "cicids2018", "synthetic"]
    raw_signals: RawSignals
    detection_rule_fired: str
    context: AlertContext


class GroundTruthLabel(BaseModel):
    disposition: Disposition
    attack_tactic: TacticOrNotApplicable
    attack_technique: str | None = None  # MITRE technique ID (e.g., "T1110.001")


class GroundTruth(BaseModel):
    """Sidecar to an Alert — paired by alert_id, never given to the triage agent."""

    alert_id: str
    ground_truth: GroundTruthLabel
    source: Literal["cicids2017", "cicids2018", "synthetic"]


class TriageOutput(BaseModel):
    """Structured output emitted by the triage agent for every alert.

    Must match the schema in augur-mitre-taxonomy. Drift = invariant violation.
    """

    alert_id: str
    disposition: Disposition
    attack_tactic: TacticOrNotApplicable
    attack_technique: str
    attack_technique_name: str
    confidence: float = Field(ge=0.0, le=1.0)
    severity: Literal["Low", "Medium", "High", "Critical"]
    recommended_action: str
    reasoning: str
    trace_id: str
```

"""Synthetic alert generator for Augur dev/test workflows.

NOT used as demo input (per spec D4 — demo runs on CICIDS only). Used
to bootstrap unit tests, exercise the triage agent without dataset
download, and inject controlled edge cases during development.

Determinism: pass a seed for reproducible alert lists. Same seed +
count => identical alert_ids and payload.
"""

import random
import uuid
from datetime import datetime, timedelta, timezone

from augur.data.enums import Disposition, Tactic
from augur.data.schema import (
    Alert,
    AlertContext,
    GroundTruth,
    GroundTruthLabel,
    RawSignals,
)

# Templates per (tactic, disposition) — controls the shape of generated alerts.
# Each template specifies the detection rule fired and a technique ID.
_TEMPLATES = [
    # Initial Access
    (Tactic.INITIAL_ACCESS, Disposition.TRUE_POSITIVE_CRITICAL,
     "Public-Web-Exploit-Pattern", "T1190", "Exploit Public-Facing Application"),
    (Tactic.INITIAL_ACCESS, Disposition.FALSE_POSITIVE,
     "Public-Web-Exploit-Pattern", "T1190", "Exploit Public-Facing Application"),
    # Credential Access
    (Tactic.CREDENTIAL_ACCESS, Disposition.TRUE_POSITIVE_CRITICAL,
     "Auth-Brute-Force", "T1110.001", "Password Guessing"),
    (Tactic.CREDENTIAL_ACCESS, Disposition.BENIGN_POSITIVE,
     "Auth-Brute-Force", "T1110.001", "Password Guessing"),
    # Lateral Movement (high FP/BP density per spec/demo target)
    (Tactic.LATERAL_MOVEMENT, Disposition.TRUE_POSITIVE_CRITICAL,
     "SMB-AdminShare-Access", "T1021.002", "SMB/Windows Admin Shares"),
    (Tactic.LATERAL_MOVEMENT, Disposition.BENIGN_POSITIVE,
     "SMB-AdminShare-Access", "T1021.002", "SMB/Windows Admin Shares"),
    (Tactic.LATERAL_MOVEMENT, Disposition.FALSE_POSITIVE,
     "SMB-AdminShare-Access", "T1021.002", "SMB/Windows Admin Shares"),
    # Exfiltration
    (Tactic.EXFILTRATION, Disposition.TRUE_POSITIVE_CRITICAL,
     "C2-Egress-Anomaly", "T1041", "Exfiltration Over C2 Channel"),
    # Command & Control
    (Tactic.COMMAND_AND_CONTROL, Disposition.TRUE_POSITIVE_POLICY_VIOLATION,
     "App-Layer-Protocol-Anomaly", "T1071.001", "Web Protocols"),
    (Tactic.COMMAND_AND_CONTROL, Disposition.BENIGN_POSITIVE,
     "App-Layer-Protocol-Anomaly", "T1071.001", "Web Protocols"),
    # Defense Evasion
    (Tactic.DEFENSE_EVASION, Disposition.TRUE_POSITIVE_POLICY_VIOLATION,
     "Process-Masquerade", "T1036.005", "Match Legitimate Name or Location"),
    (Tactic.DEFENSE_EVASION, Disposition.NEEDS_INVESTIGATION,
     "Process-Masquerade", "T1036.005", "Match Legitimate Name or Location"),
]


def generate_alerts(count: int, seed: int = 0) -> list[tuple[Alert, GroundTruth]]:
    """Return ``count`` paired (Alert, GroundTruth) tuples, deterministic per seed."""
    rng = random.Random(seed)
    base_time = datetime(2026, 5, 1, 9, 0, 0, tzinfo=timezone.utc)
    out: list[tuple[Alert, GroundTruth]] = []
    for i in range(count):
        tactic, disposition, rule, technique_id, _technique_name = rng.choice(_TEMPLATES)
        alert_id = str(uuid.UUID(int=rng.getrandbits(128)))
        ts = base_time + timedelta(minutes=i)

        signals = RawSignals(
            src_ip=f"192.168.{rng.randint(0, 255)}.{rng.randint(1, 254)}",
            dst_ip=f"10.0.{rng.randint(0, 255)}.{rng.randint(1, 254)}",
            dst_port=rng.choice([22, 80, 443, 445, 3389, 8080]),
            protocol=rng.choice(["TCP", "UDP"]),
            flow_duration_ms=rng.randint(50, 60_000),
            packet_count=rng.randint(1, 5_000),
            byte_count=rng.randint(64, 5_000_000),
            flags=rng.choice([["SYN", "ACK"], ["PSH", "ACK"], ["FIN"], []]),
        )
        context = AlertContext(
            host_role=rng.choice(
                ["workstation", "domain_controller", "server", "unknown"]
            ),
            user_account=rng.choice([None, "DOMAIN\\jdoe", "DOMAIN\\admin", "svc-backup"]),
            is_business_hours=rng.random() < 0.7,
        )
        alert = Alert(
            alert_id=alert_id,
            timestamp=ts,
            source="synthetic",
            raw_signals=signals,
            detection_rule_fired=rule,
            context=context,
        )

        # FP => no real attack => Not Applicable tactic, no technique
        if disposition == Disposition.FALSE_POSITIVE:
            label = GroundTruthLabel(
                disposition=disposition,
                attack_tactic="Not Applicable",
                attack_technique=None,
            )
        else:
            label = GroundTruthLabel(
                disposition=disposition,
                attack_tactic=tactic,
                attack_technique=technique_id,
            )
        gt = GroundTruth(alert_id=alert_id, ground_truth=label, source="synthetic")
        out.append((alert, gt))
    return out

Source of truth: augur-mitre-taxonomy skill. Out-of-scope CICIDS labels
(DDoS family, PortScan, Heartbleed, BENIGN) return the UNMAPPED_OUT_OF_SCOPE
sentinel and are dropped from the alert corpus.

CICIDS labels use a Unicode en-dash (–) in some entries (e.g., "Web
Attack – Brute Force"). The dataset's CSVs may contain that exact byte

from typing import Final

    technique_id: str

    "Bot": CicidsMapping(
        Tactic.COMMAND_AND_CONTROL, "T1071.001", "Web Protocols",
        Disposition.TRUE_POSITIVE_CRITICAL,
    ),

        "BENIGN",
        "DDoS",
        "DoS Hulk",
        "DoS GoldenEye",
        "DoS slowloris",

```python
"""CICIDS2017/2018 CSV → Alert + GroundTruth loader.

CICIDS column quirks:
- Some CSVs have leading-space columns (' Source IP'). We strip headers
  defensively.
- Protocol is numeric (6=TCP, 17=UDP, 1=ICMP) — we map back to strings.
- The Label column drives the MITRE mapping (see mitre_mapping.py).
- Out-of-scope rows (BENIGN, DDoS family, PortScan, Heartbleed) are
  silently dropped.
- Unknown labels raise KeyError (surfaces dataset drift).
"""

import uuid
from datetime import datetime
from pathlib import Path
from typing import Literal

import pandas as pd

from augur.data.mitre_mapping import UNMAPPED_OUT_OF_SCOPE, map_cicids_label
from augur.data.schema import (
    Alert,
    AlertContext,
    GroundTruth,
    GroundTruthLabel,
    RawSignals,
)

_PROTO_MAP = {6: "TCP", 17: "UDP", 1: "ICMP"}


def _norm_columns(df: pd.DataFrame) -> pd.DataFrame:
    df.columns = [c.strip() for c in df.columns]
    return df


def _row_to_pair(
    row: pd.Series,
    source: Literal["cicids2017", "cicids2018"],
) -> tuple[Alert, GroundTruth] | None:
    label = str(row["Label"]).strip()
    mapping = map_cicids_label(label)
    if mapping is UNMAPPED_OUT_OF_SCOPE:
        return None

    proto_num = int(row["Protocol"])
    protocol = _PROTO_MAP.get(proto_num)
    if protocol is None:
        # Unknown protocol — drop the row defensively
        return None

    alert_id = str(uuid.uuid4())
    ts_raw = str(row["Timestamp"]).strip()
    # CICIDS2017 timestamps come in mixed formats; pandas handles both
    ts = pd.to_datetime(ts_raw, errors="coerce")
    if pd.isna(ts):
        return None
    ts_dt = ts.to_pydatetime()

    signals = RawSignals(
        src_ip=str(row["Source IP"]),
        dst_ip=str(row["Destination IP"]),
        dst_port=int(row["Destination Port"]),
        protocol=protocol,
        flow_duration_ms=int(row["Flow Duration"]) // 1000,  # CICIDS gives microseconds
        packet_count=int(row["Total Fwd Packets"]) + int(row["Total Backward Packets"]),
        byte_count=int(row["Total Length of Fwd Packets"])
                  + int(row["Total Length of Bwd Packets"]),
        flags=[],  # CICIDS flag columns are sparse; left empty for v1
    )
    context = AlertContext(
        host_role="unknown",  # CICIDS doesn't ship host-role metadata
        user_account=None,
        is_business_hours=8 <= ts_dt.hour < 18,
    )
    alert = Alert(
        alert_id=alert_id,
        timestamp=ts_dt,
        source=source,
        raw_signals=signals,
        detection_rule_fired=label,  # the CICIDS label is the detection rule for v1
        context=context,
    )
    gt = GroundTruth(
        alert_id=alert_id,
        ground_truth=GroundTruthLabel(
            disposition=mapping.disposition,
            attack_tactic=mapping.tactic,
            attack_technique=mapping.technique_id,
        ),
        source=source,
    )
    return alert, gt


def load_cicids_csv(
    path: Path | str,
    source: Literal["cicids2017", "cicids2018"] = "cicids2017",
) -> list[tuple[Alert, GroundTruth]]:
    """Load a single CICIDS CSV file, return paired (Alert, GroundTruth) tuples.

    Out-of-scope rows are dropped silently. Unknown labels raise KeyError.
    """
    df = pd.read_csv(path, low_memory=False)
    df = _norm_columns(df)
    out: list[tuple[Alert, GroundTruth]] = []
    for _idx, row in df.iterrows():
        pair = _row_to_pair(row, source)
        if pair is not None:
            out.append(pair)
    return out
```

```python
"""Stratified train/dev/test split for Augur alert datasets.

Stratifies by ground-truth attack_tactic so each split contains a
representative tactic mix. Test set is held out — no prompt-tuning or
eval scoring touches it during development per spec D4.
"""

import random
from collections import defaultdict
from typing import TypeAlias

from augur.data.schema import Alert, GroundTruth

Pair: TypeAlias = tuple[Alert, GroundTruth]


def split_pairs(
    pairs: list[Pair],
    test_frac: float = 0.2,
    dev_frac: float = 0.1,
    seed: int = 0,
) -> tuple[list[Pair], list[Pair], list[Pair]]:
    """Return (train, dev, test) splits stratified by attack_tactic.

    Sums to len(pairs) (rounding may shift one item between splits).
    """
    if test_frac + dev_frac >= 1.0:
        raise ValueError("test_frac + dev_frac must be < 1.0")

    rng = random.Random(seed)
    by_tactic: dict[str, list[Pair]] = defaultdict(list)
    for a, gt in pairs:
        key = (
            gt.ground_truth.attack_tactic.value
            if hasattr(gt.ground_truth.attack_tactic, "value")
            else gt.ground_truth.attack_tactic  # "Not Applicable" string
        )
        by_tactic[key].append((a, gt))

    train: list[Pair] = []
    dev: list[Pair] = []
    test: list[Pair] = []

    for _tactic, group in by_tactic.items():
        rng.shuffle(group)
        n = len(group)
        n_test = round(n * test_frac)
        n_dev = round(n * dev_frac)
        test.extend(group[:n_test])
        dev.extend(group[n_test : n_test + n_dev])
        train.extend(group[n_test + n_dev :])

    rng.shuffle(train)
    rng.shuffle(dev)
    rng.shuffle(test)
    return train, dev, test
```

"""Build the train/dev/test alert corpus for Augur from CICIDS2017 + synthetic.

Run from repo root:
    uv run python scripts/build_dataset.py

Reads CSVs from data/raw/cicids2017/, augments with synthetic alerts
covering Exfiltration and Defense Evasion (which CICIDS2017 lacks),
splits 70/10/20 train/dev/test stratified by tactic, and writes JSONL
files to data/processed/.

from __future__ import annotations

import json
from collections import Counter
from pathlib import Path

from augur.data.cicids_loader import load_cicids_csv
from augur.data.splits import split_pairs
from augur.data.synthetic import generate_alerts

REPO_ROOT = Path(__file__).resolve().parents[1]
RAW_DIR = REPO_ROOT / "data" / "raw" / "cicids2017"
PROCESSED_DIR = REPO_ROOT / "data" / "processed"


def main() -> None:
    pairs = []
    csv_files = sorted(RAW_DIR.glob("*.csv"))
    if not csv_files:
        raise FileNotFoundError(
            f"No CSVs found in {RAW_DIR}. Download CICIDS2017 per Task 13.2."

            print(f"  Unknown label in {csv.name}: {e}. Inspect and update mitre_mapping.")

        gt.ground_truth.attack_tactic.value
        if hasattr(gt.ground_truth.attack_tactic, "value")
        else gt.ground_truth.attack_tactic
        for _, gt in pairs
    )
    print("Per-tactic counts:")
    for t, n in sorted(tactic_counts.items()):
        print(f"  {t}: {n}")

    train, dev, test = split_pairs(pairs, test_frac=0.2, dev_frac=0.1, seed=42)
    PROCESSED_DIR.mkdir(parents=True, exist_ok=True)
    for name, split in [("train", train), ("dev", dev), ("test", test)]:

                    "alert": alert.model_dump(mode="json"),
                    "ground_truth": gt.model_dump(mode="json"),
                }) + "\n")
        print(f"Wrote {len(split)} alerts to {path}")


if __name__ == "__main__":
    main()

# Augur Triage Agent — System Prompt v1

You are Augur, a SOC analyst assistant. Your job: classify a single security alert into a structured triage report.

## Output

Respond with ONLY a JSON object matching this exact shape — no prose, no markdown fences:

```json
{
  "alert_id": "<copy from input>",
  "disposition": "<one of: True Positive - Critical | True Positive - Policy Violation | False Positive | Benign Positive | Needs Investigation>",
  "attack_tactic": "<one of: Initial Access | Credential Access | Lateral Movement | Exfiltration | Command & Control | Defense Evasion | Not Applicable>",
  "attack_technique": "<MITRE technique ID, e.g. T1110.001>",
  "attack_technique_name": "<MITRE technique name>",
  "confidence": <0.0 to 1.0>,
  "severity": "<Low | Medium | High | Critical>",
  "recommended_action": "<short, actionable>",
  "reasoning": "<2-4 sentences explaining the decision>",
  "trace_id": ""
}
```

`trace_id` is populated downstream — leave it empty.

## Disposition Definitions

- **True Positive - Critical**: real threat, immediate IR required. Active compromise indicators.
- **True Positive - Policy Violation**: real but not emergency. Unauthorized but not active attack.
- **False Positive**: detection rule fired on activity that does NOT match what the rule was built for. The RULE is bad. (For False Positive, set attack_tactic to "Not Applicable" and attack_technique to "N/A".)
- **Benign Positive**: detection rule worked correctly, but the activity is authorized. The RULE is good; the user/system is allowed to do this.
- **Needs Investigation**: insufficient signal to disposition confidently.

## Critical: False Positive ≠ Benign Positive

A sysadmin running a legitimate admin script over SMB to a domain controller fires "SMB-AdminShare-Access" and is **Benign Positive** — the rule worked, the activity is authorized.

A buggy rule that fires on `dir \\share` (which doesn't open a remote SMB session) is **False Positive** — the rule is broken.

Conflating these signals lack of domain expertise. Be precise.

## MITRE ATT&CK Scope (6 tactics)

| Tactic | Common Techniques |
|--------|-------------------|
| Initial Access | T1190 Exploit Public-Facing Application |
| Credential Access | T1110 Brute Force (T1110.001 Password Guessing) |
| Lateral Movement | T1021 Remote Services (T1021.002 SMB/Windows Admin Shares) |
| Exfiltration | T1041 Exfiltration Over C2 Channel |
| Command & Control | T1071 Application Layer Protocol (T1071.001 Web Protocols) |
| Defense Evasion | T1036 Masquerading (T1036.005 Match Legitimate Name or Location) |

If the alert's evidence doesn't fit any of these, classify the closest match and state your uncertainty in `reasoning`. Only emit techniques from the public MITRE ATT&CK enterprise matrix.

## Severity Calibration

Anchor `severity` to industry SOC benchmarks:

- **Critical**: target FP rate < 25%. Reserve for clear active compromise.
- **High**: target FP rate < 50%. Strong signal, possibly mid-attack.
- **Medium**: target FP rate < 75%. Suspicious; needs context.
- **Low**: weak signal, mostly informational.

## Confidence

Float in [0, 1]. 0.5 means "could go either way." Don't anchor at 0.95 unless the evidence is overwhelming.

## Reasoning Style

Cite specific signal values. "Source IP 192.168.x.x to dst port 445 with 80 packets and SMB protocol." Don't say "looks suspicious" — say *what* about it is suspicious.

## Now classify this alert

Input alert (JSON):
{alert_json}
```

Note: this v1 prompt is intentionally generic and not Lateral-Movement-specific. Per the project spec's R1 mitigation, this prompt will tend to mis-classify Lateral Movement alerts as either False Positive or Benign Positive (because the prompt doesn't disambiguate the SMB admin-share / sysadmin-vs-attacker case in detail). That's by design — it sets up the demo arc the next plan exploits.

```python
"""TriageAgent — Augur's v1 alert classifier.

Single hardcoded prompt (per spec, step 5). The router + per-tactic
prompts arrive at step 6 when Firestore lands. For now, one prompt
classifies any alert.

The agent is wrapped as an ADK Agent so OpenInference auto-instruments
the LLM call. Trace ID is read from the active OpenTelemetry span and
written into the TriageOutput before returning.

LLM call is isolated in ``_call_llm`` so unit tests can mock it without
hitting Vertex.
"""

from __future__ import annotations

import json
from pathlib import Path

from google.adk.agents import Agent
from google.adk.runners import InMemoryRunner
from google.genai import types
from opentelemetry import trace

from augur.data.schema import Alert, TriageOutput

_PROMPT_PATH = Path(__file__).resolve().parents[2].parent / "prompts" / "triage_v1.md"
_MODEL = "gemini-1.5-pro-002"


class TriageAgent:
    """V1 triage agent: single prompt, classifies any alert."""

    def __init__(self) -> None:
        self._system_prompt = _PROMPT_PATH.read_text(encoding="utf-8")
        self._adk_agent = Agent(
            name="augur_triage",
            model=_MODEL,
            description="Classifies a security alert into a structured triage report.",
            instruction=self._system_prompt,
        )
        self._runner = InMemoryRunner(agent=self._adk_agent, app_name="augur")

    async def classify(self, alert: Alert) -> TriageOutput:
        alert_json = alert.model_dump_json()
        prompt = f"Input alert (JSON):\n{alert_json}"
        raw = await self._call_llm(prompt)
        try:
            payload = json.loads(raw)
        except json.JSONDecodeError as e:
            raise ValueError(f"LLM did not return valid JSON: {raw[:200]!r}") from e
        # Stamp trace_id from the active span — OpenInference set it
        span = trace.get_current_span()
        ctx = span.get_span_context() if span else None
        if ctx and ctx.is_valid:
            payload["trace_id"] = format(ctx.trace_id, "032x")
        try:
            return TriageOutput.model_validate(payload)
        except Exception as e:
            raise ValueError(f"LLM output failed schema validation: {e}") from e

    async def _call_llm(self, prompt: str) -> str:
        """Run the ADK agent and return its text response.

        Isolated as its own method so tests can mock it.
        """
        text_chunks: list[str] = []
        async for event in self._runner.run_async(
            user_id="augur",
            session_id=f"sess-{id(prompt)}",
            new_message=types.Content(
                role="user", parts=[types.Part.from_text(text=prompt)]
            ),
        ):
            if event.content and event.content.parts:
                for part in event.content.parts:
                    if part.text:
                        text_chunks.append(part.text)
        return "".join(text_chunks)
```

If the ADK runner / event-iteration shape differs in the installed version, consult the harness's `augur-adk-patterns` skill for the docs link and adjust. The contract is: send a user message containing the prompt, get back the LLM's text response.
